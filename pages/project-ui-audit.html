UX Writing · Kovai.co

Clearer Interface Content, Built into the Product Workflow

I improved interface content across Document360 2.0 and collaborated with product and UX teams on the wider user experience.

The Problem

Interface Language Needed a Shared Direction

Document360 2.0 needed clear, consistent interface language across tooltips, messages, labels, and descriptions. Content also needed to align with product behaviour and the wider user experience.

My Role

Writing, Implementation, and Collaboration

I worked as a Technical Writer, with responsibility for:

  • Audit and rewrite interface strings
  • Collaborate with Product Owners, Product Managers, and UX designers
  • Recommend improvements to navigation, interaction flows, layouts, and usability
  • Implement text updates directly in the application repository
  • Use VS Code and Git operations to maintain content changes

Process

How I Approached It

01

Audit Interface Content

I reviewed tooltips, messages, labels, and descriptions for clarity, terminology, and tone.

02

Align with Product and UX

I worked with Product Owners, Product Managers, and UX designers to connect content decisions with product behaviour and user needs.

03

Review the Wider Experience

I participated in navigation, interaction-flow, layout, and usability reviews, recommending changes alongside the product and design teams.

04

Implement Repository Updates

I edited interface strings directly in the application repository using VS Code and Git operations.

05

Standardise the Language

I applied consistent terminology and tone across the updated interface content.

Challenges & Solutions

What the Work Needed to Address

ChallengeContent across many UI elements
Labels, descriptions, messages, and tooltips needed to work together.
SolutionReview the language as a system
I audited these elements together and standardised terminology and tone.
ChallengeCopy depends on product behaviour
A clear phrase still needs to match the action or response users encounter.
SolutionCollaborate across disciplines
I worked with product and UX stakeholders and contributed usability recommendations.
ChallengeManual transfer of revised copy
Handing text changes to developers added an update step.
SolutionEdit in the application repository
I implemented string updates directly through VS Code and Git.
